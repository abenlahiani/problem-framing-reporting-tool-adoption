# Problem Framing: Reporting Tool Adoption

ALX Data Analytics course case study.

## The problem
After a legacy reporting system was shut down, operations team managers were trained on a new tool, but many went back to offline Excel trackers.

## Approach
- User persona and empathy map
- 5 Whys to reach the root cause
- Research on change management
- Data insights: shadow trackers, error rates, pass rates by competency, ADKAR scores
- Final problem statement and two opportunities for action

## Files
- `Project Mastery - Problem Framing.pdf`

## Key finding
The training taught the mechanics of the tool but not the reason for the change or the support afterwards, so adoption stalled.
